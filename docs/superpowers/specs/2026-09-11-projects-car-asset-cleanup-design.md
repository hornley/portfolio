# Projects Car Asset Cleanup Design

## Status

Approved focused pass for the `/projects/` route.

## Intent

Keep the existing scroll-driven project lap and restore the original inline SVG
track presentation. Use `projects/suzuka_max_car.png` as the moving car artwork
without introducing a raster replacement for the track.

## Scope

- Restore the existing SVG track path, base track, completed trail, and
  start/finish marker from the current route implementation.
- Keep the existing scroll progress, checkpoint, project-panel, and lap-complete
  behavior unchanged.
- Render `suzuka_max_car.png` inside the existing `#race-car` SVG group so it
  follows the same sampled path and rotation as the current car.
- Remove the `project_track.png` image element, its track-overlay CSS, and the
  unneeded raster track asset.
- Remove styling that exists only for the discarded raster-track variant.

## Composition and data flow

The SVG remains the single source of truth for track geometry. The existing
JavaScript samples `#track-path` for car position, checkpoint placement, and
completed-trail progress. The car image remains a child of `#race-car`, so its
transform continues to be generated by the existing path animation.

The project panel, responsive layout, reduced-motion handling, fallback list,
and accessibility structure remain unchanged. The car artwork is decorative and
continues to live inside the already decorative track stage.

## Error handling

No new runtime dependency or loading path is introduced. If the car image is
unavailable, the existing SVG group remains harmlessly empty; the route's
project fallback behavior remains available. The track does not depend on a
raster asset.

## Verification

1. `/projects/` contains no reference to `project_track.png`.
2. The original SVG track, trail, checkpoints, and start/finish marker remain
   present.
3. `suzuka_max_car.png` is referenced by the moving car group.
4. The car still receives the same scroll-driven translation and rotation.
5. Desktop, mobile, reverse-scroll, reduced-motion, and fallback behavior are
   unaffected.
6. The asset cleanup leaves unrelated user files and changes untouched.
